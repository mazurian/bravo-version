# bravo — sygnalizator wersji

Publiczny plik z numerem najnowszej wersji narzędzia **bravo** (`latest.json`): sam numer wersji
i krótki opis „co nowego". **Nie ma tu kodu źródłowego** — kod jest w prywatnym repozytorium.
Narzędzie czyta ten plik, żeby powiadomić właściciela sklepu, że jest nowsza wersja.
